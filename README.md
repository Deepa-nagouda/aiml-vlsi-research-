# AI/ML Applied to VLSI Design

> Applying Machine Learning and Artificial Intelligence techniques to solve challenges in VLSI (Very Large Scale Integration) design — bridging the gap between modern AI and hardware engineering.

---

## Problem Statement

Traditional VLSI design processes are time-consuming, highly complex, and dependent on manual expert intervention. This research explores how AI/ML models can automate, optimize, and improve accuracy in VLSI design workflows — reducing design time and improving circuit performance.

---

## Research Objectives

- Investigate how ML algorithms can be applied to VLSI design challenges
- Build and evaluate models that assist in design optimization
- Analyze performance improvements over traditional approaches
- Contribute a reproducible, open-source implementation for the research community

---

## Tech Stack

| Category | Tools / Libraries |

| VLSI Domain | VLSI design concepts & circuit datasets |
| Environment | Jupyter Notebook / VS Code |

---

## Methodology

1. **Data Collection** — Gathered VLSI circuit datasets and design parameters
2. **Preprocessing** — Cleaned and normalized data using NumPy and Pandas
3. **Model Development** — Built and trained ML/DL models to learn design patterns
4. **Evaluation** — Measured model performance using accuracy, loss, and domain-specific metrics
5. **Optimization** — Iteratively refined the model across multiple versions for best results
